**Six seasons deep in event data. Next stop: recruitment.**

On the side I write **[The Cutback](https://the-cutback.beehiiv.com/)**, where I publish recruitment-style research — transfer corridor analysis, player profiling, and metrics built from event data — with every methodology open for inspection.

## The toolkit

Notebooks and tools in this repo, mapped to the recruitment workflow they serve:

### Stage 1 — Define the role
- 📔 [**Position Clustering**](https://gibranium.github.io/positioncluster/) — grouping players into data-defined roles, the position feature behind any profiling system

### Stage 2 — Pick the market
- 📔 [**Team Style Similarity**](https://gibranium.github.io/teamstyle/) — rating stylistic closeness between clubs from possession chain features, to find where a target would adapt

### Stage 3 — Evaluate players
- 📔 [**Defensive Value**](https://gibranium.github.io/defensivevalue/) — a metric to rate individual defending from event data
- 📔 [**Passing Under Pressure**](https://gibranium.github.io/underpressure/) — a press-resistance proxy without pressure-specific event data
- 📂 [**Passing**](https://gibranium.github.io/passing/) — pass sonars, actual vs expected completion, contextual pass maps, positional passing clusters
- 📂 [**Ability**](https://gibranium.github.io/ability/) — passing and shooting overperformance vs model expectation
- 📂 [**Carries**](https://gibranium.github.io/carries/) — carry maps and carrying production metrics

### Stage 4 — Communicate
- ⚡ [**Throw-In Analysis**](https://setpiecesanalysis.streamlit.app) — a live Streamlit app: the research pipeline behind The Cutback's set-piece coverage, made queryable
- 📂 [**Maps**](https://gibranium.github.io/maps/) — shot maps, assist maps, heat maps
- 📂 [**Other Visualizations**](https://gibranium.github.io/others/) — xG trend lines, box entries, receiving ability, metric consistency, and more
